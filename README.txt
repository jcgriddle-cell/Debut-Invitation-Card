THE GOLDEN HOUR DEBUT INVITATION

Mobile-ready Victorian debut invitation based on the supplied files.

FILES
- index.html
- style.css
- script.js
- celebrant.png (transparent-background celebrant frame/photo)

HOW TO USE
1. Open the folder in Visual Studio Code.
2. The included celebrant.png already has the outside background removed.
3. Open index.html or use Live Server.

The existing invitation content, program, names, date, venue, and animations are preserved.
The celebrant photo area is responsive and scales for phones, tablets, and desktops.
